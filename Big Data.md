#  BIG DATA
## 1. ¿Qué es el Big Data?

**Big Data** es el conjunto de tecnologías, herramientas y técnicas utilizadas para **recopilar, almacenar, procesar y analizar grandes cantidades de datos** que, por su volumen, velocidad o complejidad, no pueden ser tratados fácilmente mediante los sistemas tradicionales.

Actualmente generamos una enorme cantidad de información cada día mediante:

-  Redes sociales y teléfonos móviles.
-  Compras por Internet.
-  Operaciones bancarias.
-  Vehículos y dispositivos GPS.
-  Sensores industriales.
-  Hospitales y sistemas sanitarios.
-  Páginas web y aplicaciones.
-  Dispositivos conectados mediante IoT.

El objetivo del Big Data no es simplemente **guardar datos**, sino conseguir información útil a partir de ellos para **tomar mejores decisiones, detectar problemas y encontrar patrones**.


---

## 2. ¿Cómo funciona el Big Data?

El funcionamiento del Big Data se puede dividir en varias etapas:

** Recopilación de datos -  Almacenamiento -  Procesamiento -  Análisis -  Visualización -  Toma de decisiones**

---

# 3. Tipos de Big Data

Los datos utilizados en Big Data pueden clasificarse principalmente en **tres tipos**:

| Tipo de dato | Características | Ejemplos |
|---|---|---|
| **Estructurados** | Tienen una estructura organizada | Tablas, bases de datos, facturas |
| **No estructurados** | No tienen un formato fijo | Vídeos, imágenes, audios, publicaciones |
| **Semiestructurados** | Tienen cierta organización, pero no una estructura rígida | JSON, XML, correos electrónicos |

### 📋 Datos estructurados

Son datos organizados normalmente en **filas y columnas**, como los que encontramos en una base de datos SQL.

**Ejemplo:**

| ID | Nombre | Edad |
|---|---|---|
| 1 | Carlos | 20 |
| 2 | Laura | 21 |
| 3 | Pedro | 19 |

###  Datos no estructurados

No siguen una estructura determinada. Algunos ejemplos son:

- Fotografías.
- Vídeos.
- Audios.
- Comentarios de redes sociales.
- Documentos de texto.

###  Datos semiestructurados

Tienen cierta organización mediante etiquetas o campos, pero no siguen necesariamente una estructura de tabla.

Algunos ejemplos son **JSON y XML**.

# 4. Características del Big Data: las 5 V

Las características principales del Big Data se suelen explicar mediante las **5 V**:

| Característica | Significado | Explicación |
|---|---|---|
| **Volumen**  | Cantidad | Se generan enormes cantidades de datos. |
| **Velocidad**  | Rapidez | Los datos se generan y procesan rápidamente. |
| **Variedad**  | Tipos | Existen datos de diferentes formatos y fuentes. |
| **Veracidad**  | Calidad | Es importante que los datos sean fiables y correctos. |
| **Valor**  | Utilidad | Los datos deben proporcionar información útil. |



# 5. Arquitectura del Big Data

La arquitectura de Big Data está formada por diferentes componentes que trabajan conjuntamente para **recopilar, almacenar, procesar y analizar información**.
### 1. Fuentes de datos

Son los lugares de donde procede la información.

Por ejemplo:

- Redes sociales.
- Páginas web.
- Sensores.
- Aplicaciones.
- Bases de datos.
- Dispositivos móviles.

### 2. Ingesta de datos

Es el proceso mediante el cual los datos son **recibidos y transportados** hacia los sistemas donde serán almacenados y procesados.

### 3. Almacenamiento

Permite guardar grandes cantidades de información.

Se pueden utilizar:

- Servidores.
- Bases de datos.
- Sistemas distribuidos.
- Almacenamiento en la nube.

### 4. Procesamiento

Los datos son transformados y preparados para poder analizarlos.
### 5. Análisis

Se estudian los datos para encontrar:

- Patrones.
- Tendencias.
- Relaciones.
- Anomalías.
- Predicciones.



# 6. Ventajas y desventajas del Big Data

| ✅ Ventajas | ❌ Desventajas |
|---|---|
| Permite analizar grandes cantidades de información. | Puede tener un coste elevado. |
| Ayuda a tomar mejores decisiones. | Requiere personal especializado. |
| Permite detectar tendencias y patrones. | La gestión de los datos puede ser compleja. |
| Mejora productos y servicios. | Existen riesgos relacionados con la privacidad. |
| Permite trabajar con datos en tiempo real. | Los datos incorrectos pueden producir resultados erróneos. |
